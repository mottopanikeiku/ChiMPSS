# Source of these files

These are version-controlled copies of the 5-HT2B v2 campaign scripts. **The
copies that SLURM actually executes live on Expanse** at
`/expanse/lustre/projects/iit127/fcetin/5ht2b/v2/scripts/` (paths in the scripts
are absolute and point there). When a runtime script changes, copy it here and
commit it, so this directory stays a faithful history of what ran.
